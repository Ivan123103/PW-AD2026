1. git init. Inicializa un nuevo repositorio de Git en la carpeta actual.

Ejemplo de caso de uso: Crear un repositorio para un proyecto nuevo.

2. git clone. Crea una copia local de un repositorio remoto.

Ejemplo de caso de uso: Descargar un proyecto de GitHub para trabajar en él.

3. git status. Muestra el estado actual del repositorio, incluyendo archivos modificados, nuevos o pendientes de agregar.

Ejemplo de caso de uso: Comprobar qué archivos han cambiado antes de realizar un commit.

4. git add (sin punto). Agrega uno o varios archivos al área de preparación (staging area) para incluirlos en el próximo commit.

Ejemplo de caso de uso: Preparar un archivo modificado para guardarlo en el historial.

5. git add. (con punto). Agrega todos los archivos nuevos y modificados de la carpeta actual al área de preparación.

Ejemplo de caso de uso: Preparar todos los cambios realizados en un proyecto antes de hacer un commit.

6. git commit. Guarda los cambios que se encuentran en el área de preparación dentro del historial del repositorio.

Ejemplo de caso de uso: Registrar una nueva funcionalidad desarrollada en el proyecto.

7. git log. Muestra el historial de commits realizados en el repositorio.

Ejemplo de caso de uso: Revisar los cambios realizados anteriormente y saber quién los realizó.

8. git branch. Permite visualizar, crear y administrar ramas dentro de un repositorio.

Ejemplo de caso de uso: Consultar las ramas disponibles en un proyecto.

9. git switch. Permite cambiar de una rama a otra dentro del repositorio.

Ejemplo de caso de uso: Cambiar de la rama principal a una rama de desarrollo.

10. git switch -c. Crea una nueva rama y cambia automáticamente a ella.

Ejemplo de caso de uso: Crear una rama para desarrollar una nueva función sin modificar directamente la rama principal.

11. git merge. Combina los cambios realizados en una rama con otra rama.

Ejemplo de caso de uso: Integrar una función terminada de la rama desarrollo en la rama principal.

12. git remote. Permite administrar y consultar las conexiones del repositorio local con repositorios remotos.

Ejemplo de caso de uso: Consultar qué repositorio remoto está asociado al proyecto.

13. git fetch. Descarga información y cambios del repositorio remoto, pero no los integra automáticamente en la rama actual.

Ejemplo de caso de uso: Comprobar si existen nuevos cambios en GitHub sin modificar todavía el código local.

14. git pull. Descarga los cambios de un repositorio remoto y los integra en la rama actual.

Ejemplo de caso de uso: Actualizar el proyecto local con los cambios que otros integrantes del equipo subieron a GitHub.

15. git push. Envía los commits realizados localmente hacia un repositorio remoto.

Ejemplo de caso de uso: Subir los cambios realizados en el proyecto a GitHub.

16. git diff. Muestra las diferencias entre los archivos modificados y la última versión registrada.

Ejemplo de caso de uso: Revisar exactamente qué líneas fueron modificadas antes de realizar un commit.

17. git restore. Permite descartar cambios realizados en archivos que todavía no han sido confirmados mediante un commit.

Ejemplo de caso de uso: Deshacer accidentalmente los cambios realizados en un archivo.

18. git reset. Permite quitar archivos del área de preparación o regresar el repositorio a un estado anterior, dependiendo de la opción utilizada.

Ejemplo de caso de uso: Quitar un archivo del área de preparación antes de realizar un commit.

19. git rm. Elimina un archivo del proyecto y registra su eliminación para el siguiente commit.

Ejemplo de caso de uso: Eliminar un archivo que ya no se necesita dentro del proyecto.

20. git stash. Guarda temporalmente los cambios actuales sin necesidad de realizar un commit.

Ejemplo de caso de uso: Guardar temporalmente el trabajo que estás realizando para poder cambiar de rama y trabajar en otra tarea.
